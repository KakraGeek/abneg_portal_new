# ABNEG Portal SEO Implementation Guide

## Overview
This document outlines the comprehensive Search Engine Optimization (SEO) implementation for the ABNEG (Agric Business Network Ghana) portal.

## Implemented SEO Features

### 1. Meta Tags & Page Titles
- **Dynamic page titles** with "ABNEG - [Page Name]" format
- **Meta descriptions** optimized for each page
- **Keywords** targeting agricultural business terms
- **Open Graph tags** for social media sharing
- **Twitter Card tags** for Twitter sharing
- **Canonical URLs** to prevent duplicate content

### 2. Structured Data (Schema.org)
- **Organization schema** for ABNEG entity
- **AboutPage schema** for about page
- **ContactPage schema** for contact page
- **Event schema** for events page
- **NewsArticle schema** for news page
- **FinancialService schema** for loan applications
- **PaymentService schema** for payments

### 3. Technical SEO
- **Sitemap.xml** for search engine crawling
- **Robots.txt** for crawler guidance
- **Preconnect links** for performance
- **Viewport meta tags** for mobile optimization
- **Theme color** for browser UI consistency
